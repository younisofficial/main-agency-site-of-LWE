=============================================

1) Is zip ko apne project folder (main-agency-site) ke andar extract karein.
   Windows poochay "Replace files?" to "Replace all / Yes to all" karein.
   (Is zip mein .env, vendor ya node_modules NAHI hain — aap ki settings safe hain.)

2) Purani dummy images delete kar sakte hain (zaroori nahi):
   public/images/portfolio/sample-1.svg ... sample-9.svg
   public/images/team/member-1.svg ... member-7.svg

3) Terminal mein project folder mein yeh commands chalayein (ek ek kar ke):
   php artisan migrate
   php artisan db:seed
   php artisan config:clear
   npm run build

   - migrate: database mein PKR price range ka naya column banata hai,
     aur contact form mein email optional kar deta hai.
   - db:seed: nayi services, PKR prices aur Recent Work (6 projects) daal deta hai.

4) ZAROORI — apni asli details likhein: config/agency.php
   'phone'    => '+92 300 0000000'   <- apna number
   'whatsapp' => '923000000000'      <- apna WhatsApp number (sirf digits, 92 se shuru, 0 ke baghair)
   'email', 'address', 'hours'       <- apni details
   Har "WhatsApp us" aur "Order on WhatsApp" button isi number par jata hai.
   Badalne ke baad: php artisan config:clear
